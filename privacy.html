gmail-tidy privacy policy

gmail-tidy is a personal tool used only by its owner, on their own Gmail account.

What it accesses

With the owner's permission, it reads message metadata (sender, subject, date, size) and changes labels on messages in the owner's Gmail account. It can also create labels and filters there. It cannot permanently delete mail.

Where data goes

Everything runs on the owner's own computer. No Gmail data is sent to any server other than Google's, and none is shared with, sold to or used by anyone else. A local log of message IDs it changed is kept on that computer so changes can be undone.

Google API Services User Data Policy

gmail-tidy's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
